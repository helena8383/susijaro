# 블로그 글 작성 가이드 (오사카 스시자로 투어 가이드)

이 가이드는 "1개월 17,900엔부터 34,000엔까지, 오사카 마운자로 가격 지도" 글의 구조를 뽑아 만든 것입니다.
새 글은 `글템플릿.html`을 복사해서 `posts/` 폴더에 새 이름으로 저장한 뒤, 이 가이드의 순서대로 채웁니다.

## 1. 사용 순서
1. `글템플릿.html`을 `posts/주제-영문이름.html`로 복사합니다. (예: `posts/korea-customs-rules.html`)
2. `{{ }}`로 표시된 칸을 모두 채웁니다. 안 쓰는 블록은 통째로 지웁니다.
3. 조사 폴더(`오사카여행_조사자료`)에서 사실 정보를 찾아 옮깁니다.
4. 아래 체크리스트로 확인합니다.
5. `index.html`의 해당 글감 카드에서 상태를 "발행"으로 바꾸고, 제목에 글 링크를 겁니다.
6. `sitemap.xml`에 새 글 주소와 작성일을 한 줄 추가합니다. (검색엔진이 새 글을 빨리 찾습니다)

## 2. 글 구조 (도입 → 본문 → 마무리)

### 도입
- **제목 아래 정보줄**: 카테고리 칩, 작성일, 한 줄 출처 안내 (예: "조사 자료 기준, 직접 방문 전")
- **첫 문단**: 여행 상황 한두 문장 + 이 글이 무엇을 다루는지
- **범위 선언**: "조사 자료에 나온 정보만 썼고, 확인하지 못한 것은 '확인 못함'이라고 적었다"
- **용어 상자**: 어려운 말을 쉬운 말로 풀어 줍니다. (예: 1펜, 자유진료)
- **제목과 본문이 어긋나는 부분이 있으면 설명 상자**를 둡니다. (예: 제목의 범위를 넘는 값)

### 본문 (소제목 3~4개)
| 순서 | 역할 | 쓰는 형태 |
|---|---|---|
| ① | 한눈에 보는 핵심 비교 | 막대 그래프 또는 표 |
| ② | 대상별 확인된 사실 (주소·시간·조건) | 표 (확인 못한 칸은 "확인 못함") |
| ③ | 숨은 조건이나 추가 비용, 직접 계산 | 표 + 계산식 목록 |
| ④ | 주의할 점과 아직 확인하지 못한 것 | 경고 상자 + 목록 |

- 소제목은 `본문 ①`처럼 순서를 붙여 씁니다. 순서가 실제로 의미 있는 글에서만 사용합니다.
- 계산한 숫자는 반드시 계산식을 옆에 적습니다.
- 추정한 숫자는 "제 추정치"라고 밝힙니다.

### 마무리
- **정리**: 핵심 3줄
- **다음에 할 일 상자**: 독자가 바로 쓸 수 있는 체크리스트 (예: 예약 전에 물어볼 것)
- **다음 글 예고** 또는 업데이트 약속: 한 문장
- **안내 상자**: 의료 조언이 아니라는 문구, 조사 시점, 가격이 바뀔 수 있다는 문구 (해당할 때)
- **참고한 자료**: 링크 목록

## 3. 사실 정보 규칙 (가장 중요)
- 주소, 가격, 운영 시간, 평점 같은 **사실 정보는 조사 폴더에 있는 내용만** 씁니다.
- 폴더에 없으면 지어내지 말고 **"확인 못함"**이라고 적습니다.
- 평점은 출처(구글 지도 블로그 표기, 타베로그 등)를 함께 적습니다. 출처가 다른 점수는 직접 비교하지 않습니다.
- 가격에는 세금 포함 여부, 1펜/4펜 같은 기준을 적습니다. 자료에 없으면 적지 않습니다.
- 직접 다녀오지 않은 곳은 후기처럼 쓰지 않습니다. "조사한 바로는"으로 씁니다.
- 제목에 단정적인 결론을 넣으려면 본문에 그 근거가 있어야 합니다.

## 4. 문체
- 한국어, 인사말 없이 바로 본론
- 쉬운 말로 풀어쓰기 (전문 용어는 한 번 설명)
- 유쾌하되 사실은 정확하게
- 문단은 짧게, 표와 목록으로 정리

## 5. 발행 전 체크리스트
- [ ] 제목과 본문 내용이 맞는가 (범위, 숫자)
- [ ] 모든 사실 정보가 조사 폴더에 있는 내용인가
- [ ] 조사 폴더에 없는 값에 "확인 못함"을 적었는가
- [ ] 계산한 숫자에 계산식이 있는가, 추정치에 "추정"을 적었는가
- [ ] 평점·가격에 출처와 기준을 적었는가
- [ ] 도입 · 본문 · 마무리 구조가 지켜졌는가
- [ ] 안내 상자(의료 조언 아님 등)가 필요한 글에 들어갔는가
- [ ] 참고 자료 링크가 들어갔는가
- [ ] `index.html` 카드 상태와 링크를 바꿨는가
- [ ] `sitemap.xml`에 새 글을 추가했는가
- [ ] 제목·설명·작성일이 `<title>`, 공유 태그, `ld+json`에서 모두 같은가
